# Make the AI Judge Laugh: Office Jokes

One-line joke about office life, 200 characters max. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
